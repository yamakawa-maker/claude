## 1. 漢字・ひらがな

| 漢字表記 | 使用形 | 備考 |
|---------|--------|------|
| 事 | こと | |
| 物 | もの | |
| 為 | ため | |
| 出来る | できる | |
| 下さい | ください | |
| 致します | いたします | |
| 頂く | いただく | 補助動詞の場合 |
| 頂く | 頂く | 「頂く（もらう）」の実質動詞は漢字 |

---

## 2. 数字・単位

- 数字は半角。3桁区切りカンマあり（例: 1,000円、12,345人）
- 日付は `YYYY年M月D日`（例: 2026年5月15日）
- パーセントは `%`（半角）
- 単位はアラビア数字＋単位記号（例: 3km、500g）

---

## 3. 句読点・記号

- 読点は `、`、句点は `。`
- 中黒 `・` はリスト区切り・並列に使用
- 引用符: 「」（一重）、『』（二重・書名・強調引用）
- 省略記号は `……`（全角2つ）。`...` は使わない

---

## 4. 引用・出典

- 引用は「」で囲み地の文と明確に区別する
- 引用元URL・取材日・取材相手を必ず明記
- ブロック引用は `>` で表示（Markdown）

---

## 5. 禁止・注意表現

| 種別 | 内容 |
|------|------|
| ステマ・広告表現 | 「絶対」「必ず」「100%」などの断定的効能表現 |
| 誇大表現 | 根拠のない最上級（「最高の」「唯一の」） |
| 個人情報 | 実名・住所・連絡先（取材対象者を含む） |
| 機密情報 | 競合他社・取引先の未公開情報 |
| エンバーゴ情報 | 解禁前の情報は `research/<題名>/embargo.md` に隔離 |

---

## 6. 文章ルール（推敲チェックリスト共通）

- 一文は80字以内を目安にする
- 主語と述語は近づける
- 同じ語尾を3連続させない（「です。です。です。」など）
- 接続詞（そして／また／しかし）の連続は避ける
- 受動態は能動態に書き換えられないか確認する

---

## 7. 媒体別ルール

媒体固有のルールは `writing/tone/<媒体名>.md` に記載する。
スタイルガイドと矛盾する場合は **媒体別ルールを優先** する。
