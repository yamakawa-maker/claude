# アンケートメール 確定版全文

作成日: 2026年11月20日
修正の意図: [2026-11-20-アンケートメール修正意図.md](2026-11-20-アンケートメール修正意図.md)

| 通 | 送る場面 |
|----|----------|
| 1通目 | 反響後、営業から電話してつながった（最初の商談が済んだ） |
| 2通目 | 反響後、営業から電話したがつながらなかった |
| 3通目 | 前の反響から30日以上たって再び問い合わせがあった（1通目・2通目の代わりに送る） |
| 4通目 | 決済・引渡しから6カ月後 |

---

## 1通目：電話がつながった場合

```
件名：【リタ不動産】お電話でのお時間ありがとうございました（1分のアンケート）

{お客様名} 様

リタ不動産の{担当者名}でございます。
先日は{媒体名}よりお問い合わせいただき、お電話でもお時間を頂戴し、誠にありがとうございました。

今後のご案内をよりよくするため、1分ほどのアンケートにご協力いただけますでしょうか。
私どもの対応で良かった点・至らなかった点を、率直にお聞かせください。

▼ アンケートはこちら（お客様専用のページです）
{アンケートURL}

・スマートフォンからもご回答いただけます
・いただいたご意見は、ご案内の改善にのみ使用いたします

ご不明な点は、このメールにそのままご返信ください。

──────────────────
株式会社リタ不動産
担当：{担当者名}
TEL 03-5357-7757
https://ritamatch.com
──────────────────
```

> 未確認: 電話した当日に送る場合は「先日は」を「このたびは」にする。
